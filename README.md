# Amir Patel portfolio

Static site. No build step. Open index.html or host on GitHub Pages.

- `index.html` is the current portfolio: every project sits in a small in-page database and the page runs a SQL console over it.
- `legacy/` keeps the earlier black and orange portfolio. It is also tagged `legacy-black-orange`, so `git checkout legacy-black-orange -- index.html` brings it back as the homepage.
- Role links: add `#analyst`, `#engineer`, `#bi` or `#ml` to the address to open the page sorted for that role.
