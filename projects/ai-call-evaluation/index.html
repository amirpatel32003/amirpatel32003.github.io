Experience - AI / Quality Assurance

AI Call Evaluation Platform ("Great Calls")

Automated pipeline pulling call recordings via Twilio, transcribing with Whisper, and scoring against a structured rubric with GPT. It also compares each call to the company's call standards and writes personalized coaching notes for every agent, supporting employee mentoring. Replaced manual QA review and integrated directly into the internal e-portal.

An 80-second narrated walkthrough, stage by stage. Captions are on, so it works with the sound off too. It's kept generic on purpose, so it shows the design without internal specifics.

Breakdown

The six stages

  1. Trigger and fetch

    The portal calls a Flask API with a recording ID. The API pulls the recording and its call details from Twilio.

    FlaskTwilio

  2. Transcribe audio

    The intro of the recording is trimmed, then Whisper turns the audio into a text transcript.

    PythonWhisper

  3. Identify the agent

    GPT matches the name spoken on the call to the agents on shift at that time. If no name comes up, it falls back to the closest shift start.

    GPT-4oSQL Server

  4. Score against a rubric

    GPT scores the transcript against a structured rubric, criterion by criterion. The overall score is the share of criteria met.

    GPT-4oPython

  5. Generate personalized feedback

    The call is compared against a call-standards guide covering how to open a call, handle objections, and answer common customer questions. GPT writes coaching notes specific to that agent and that call.

    GPT-4oPython

  6. Save and serve

    Scores, transcript, and coaching notes are saved to a database and returned to the portal as JSON. Managers get a one-click report with sign-off and PDF export.

    SQL ServerREST API
